# Bureau d'Analyse Terrestre — relevés Klaxo-3

Analyse des signalements d'OVNI collectés par la sonde Klaxo-3.

## Utilisation

```bash
python3 analyse.py
```

Le script télécharge `releves_klaxo3.csv` si besoin, puis exécute chaque phase de l'analyse.
Les résultats et décisions sont détaillés dans [RAPPORT.md](RAPPORT.md).
